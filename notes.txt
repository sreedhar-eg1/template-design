While using 7 in 1 rule, we willl create partial files
Partial files is created by placing underscore before filename
Ex _base.SCSS

This partial file can be imported using @imported
@import 'base/base'

while importing, underscore and file extension .scss are omitted

we cant use sass variable inside calc like we use in other places
i.e like width: calc((100% - $gutter-horizontal) / 2);
instead, we need to use #{$gutter-horizontal}
i,e width: calc((100% - #{$gutter-horizontal}) / 2);

[class^="col-"] => any class that starts with col-
[class*="col-"] => any class that contains col-
[class$="col-"] => any class that ends with col-

a > b => select b which is a dirext child of a 

While applying transition, we can specify perspective to get better visual effect
